ANIMALARIO DE RATONES

--DESCRIPCION DEL PROYECTO---

El objetivo de esta práctica,es implementar una aplicación que permita
gestionar poblaciones de ratones de laboratorio mediante una interfaz de consola.

--FUNCIONALIDADES--

Yo he decidido utilizar arrayList y no ninguna otra forma
porque por ahora es con lo que mejor se trabajar.
Es posible que para la entrega 2 esto pueda cambiar.

La aplicacion nos permite realizar :
- Crear nuevas poblaciones de ratones.

- Abrir poblaciones almacenadas en archivos CSV.

- Añadir ratones a una población.

- Listar los ratones existentes.

- Eliminar y modificar ratones.

- Consultar los datos de un ratón.

- Gestionar mutaciones cromosómicas.

- Determinar si un ratón es estéril o polígamo.

- Guardar poblaciones en archivos CSV.

---ESTRUCTURA DEL PROGRAMA---

El proyecto está organizado en las siguientes clases:

Main.java: inicia la ejecución del programa.

Menu.java: gestiona las opciones del menú.

Ratones.java: representa los datos de cada ratón.

Poblaciones.java: gestiona los ratones de una población.

CromosomasSexualesYMutaciones.java: representa las mutaciones cromosómicas.

GestorCSV.java: permite guardar y recuperar poblaciones mediante archivos CSV.
